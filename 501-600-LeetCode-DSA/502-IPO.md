# <u>502. IPO</u>

----

## 🔗 Problem Link
https://leetcode.com/problems/ipo/

---

## 🧠 Intuition:
* 🔹 Pair each project's **capital requirement** with its **profit** so both values stay together.

* 🔹 Sort all projects by their required capital in **ascending order**.

* 🔹 Use a **Max Heap (Priority Queue)** to always keep track of the most profitable projects that can currently be afforded.

* 🔹 Start with the initial capital `w`.

* 🔹 For each of the `k` project selections:
    - Add all projects whose required capital is less than or equal to the current capital into the max heap.
    - If no project is affordable, stop early because no further progress is possible.
    - Otherwise, pick the project with the maximum profit from the heap.
    - Add its profit to the current capital, increasing the budget for future projects.

* 🔹 Repeat until `k` projects are completed or no more feasible projects remain.

* 🔹 This greedy strategy always chooses the most profitable project among all currently available ones, maximizing the final capital.

---

## ⏱ Time Complexity

**O(n log n + k log n)**

* Sorting takes `O(n log n)`
* Each project is inserted/removed from the max heap at most once.
    
---

## 📦 Space Complexity

**O(n)**

* For the project array and the max heap.

---

## 💻 Java Code

```java
class Solution {
    public int findMaximizedCapital(int k, int w, int[] profits, int[] capital) {
        int n = capital.length;
      
        PriorityQueue<int[]> minCapitalHeap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
      
        for (int i = 0; i < n; i++) {
            minCapitalHeap.offer(new int[] {capital[i], profits[i]});
        }
      
        PriorityQueue<Integer> maxProfitHeap = new PriorityQueue<>((a, b) -> b - a);
      
        while (k-- > 0) {
            while (!minCapitalHeap.isEmpty() && minCapitalHeap.peek()[0] <= w) {
                maxProfitHeap.offer(minCapitalHeap.poll()[1]);
            }
          
            if (maxProfitHeap.isEmpty()) {
                break;
            }
          
            w += maxProfitHeap.poll();
        }
      
        return w;
    }
}
```
