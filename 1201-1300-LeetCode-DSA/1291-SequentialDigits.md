# <u>1291. Sequential Digits</u>

----

## 🔗 Problem Link
https://leetcode.com/problems/sequential-digits/

---

## 🧠 Intuition:
* 🔹 A sequential digit number is formed by appending consecutive digits in increasing order (e.g., 123, 4567, 6789).

* 🔹 Try every possible starting digit from **1 to 8**.

* 🔹 For each starting digit, keep appending the next consecutive digit to build larger sequential numbers.

* 🔹 After each new digit is appended, check whether the generated number lies within the range [`low`, `high`].

* 🔹 If it is within the range, add it to the `result` list.

* 🔹 Continue until the next digit would exceed **9**, since no further sequential number can be formed.

* 🔹 Finally, sort the collected numbers because they are generated by different starting digits and may not be in ascending order.

---

## ⏱ Time Complexity

**O(1)**

* At most **36** sequential numbers can be generated, and sorting this fixed-size list is constant time.
    
---

## 📦 Space Complexity

**O(1)**

* The auxiliary space is constant (excluding the output list).

---

## 💻 Java Code

```java
class Solution {
    public List<Integer> sequentialDigits(int low, int high) {
        List<Integer> result = new ArrayList<>();
      
        for (int startDigit = 1; startDigit < 9; ++startDigit) {
            int currentNumber = startDigit;
          
            for (int nextDigit = startDigit + 1; nextDigit < 10; ++nextDigit) {
                currentNumber = currentNumber * 10 + nextDigit;
              
                if (currentNumber >= low && currentNumber <= high) {
                    result.add(currentNumber);
                }
            }
        }
      
        Collections.sort(result);
      
        return result;
    
    }
}

```
