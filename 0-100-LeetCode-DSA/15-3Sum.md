# <u>15. 3Sum</u>

----

## 🔗 Problem Link
https://leetcode.com/problems/3sum/

---

## 🧠 Intuition:
* 🔹 First, sort the array so numbers are in increasing order; this helps use the two-pointer technique and avoid duplicates easily.
* 🔹 Fix one number nums[f] at a time and try to find two other numbers whose sum makes the total equal to 0.
* 🔹 After fixing the first number, treat the remaining part of the array as a Two Sum problem.
* 🔹 Use two pointers:
    - i → next element after fixed index (left pointer)
    - j → last element (right pointer)
* 🔹 Calculate sum = nums[f] + nums[i] + nums[j].
    - If sum is too large, move right pointer left (j--) to reduce sum.
    - If sum is too small, move left pointer right (i++) to increase sum.
    - If sum becomes 0, we found a valid triplet → store it.
* 🔹 After finding a triplet, move both pointers and skip duplicate values to avoid repeated answers.
* 🔹 Also skip duplicate fixed elements in the outer loop so each triplet is unique.
* 🔹 Stop early if fixed number becomes positive because remaining numbers will also be positive (sum cannot be 0).

---

## ⏱ Time Complexity

**O(n^2)**

* **1️⃣ Sorting :** O(nlogn)
* **2️⃣ Main Loop + Two Pointers**
    - Outer loop runs n times.
    - Two pointers together scan array once → O(n).
    
---

## 📦 Space Complexity

**O(k)**

* Where :
    - where `k` = number of triplets

---

## 💻 Java Code

```java
class Solution {
    private void twoSumHelper(int f, int nums[], List<List<Integer>> result){
        int i = f + 1, j = nums.length - 1;

        while(i < j){
            int sum = nums[f] + nums[i] + nums[j];

            if(sum > 0){
                j--;
            } else if(sum < 0){
                i++;
            } else{
                result.add(Arrays.asList(nums[f], nums[i], nums[j]));
                i++;
                j--;

                while(i < j && nums[i] == nums[i - 1]){
                    i++;
                }

                while(i < j && nums[j] == nums[j + 1]){
                    j--;
                }
            }

        }
    }
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> result = new ArrayList<>();

        for(int i = 0; i < nums.length; i++){
            if(nums[i] > 0){
                break;
            }

            if(i == 0 || nums[i] != nums[i - 1]){
                twoSumHelper(i, nums, result);
            }
        }

        return result;
    }
}
```
